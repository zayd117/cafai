# docs/design

Design-session output for CAF.ai. Design only; the app is not changed by anything in this folder.

| File | What it is |
|---|---|
| `UX_DECISIONS.md` | Status, the Figma blocker, what changed in the visual direction and why, proposals awaiting approval, collision decision |
| `COMPONENT_MAP.md` | Figma component → expected frontend component → location, plus old→new token map |
| `tokens.css` | CSS custom properties generated from the Figma variables (proposal, not imported) |
| `tokens.json` | Same tokens as data |

Figma: https://www.figma.com/design/1gCS6RVfLxkdP3AH95D4UY

Source-of-truth order: Master Plan v3.1 (what the product does) → Figma (how it looks) → this repo (what is implemented).
